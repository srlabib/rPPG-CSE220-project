Ground Truth Data Format Guide

The platform supports two ground truth formats for evaluation:

Option 1: Standard CSV (Recommended)

A comma-separated file with timestamp (seconds) and hr (BPM):

timestamp,hr 0.0,72.4 0.5,72.8 1.0,73.1 1.5,73.5 2.0,73.9

Option 2: UBFC Dataset Format (.txt)

The 3-line format used in standard UBFC-rPPG datasets (e.g. subject10/ground_truth.txt):

Line 1: 0.12 0.15 0.18 ... (PPG signal) Line 2: 72.5 72.8 73.1 ... (Heart rate BPM) Line 3: 0.033 0.066 0.099 ... (Timesteps in seconds)

✅ The system automatically detects either format upon upload.
